# GitHub Upload Checklist — Slipper in the Woods

Do not upload `node_modules`. It is generated by `npm install` on your machine and by Cloudflare during deployment.

## Upload these

- `.github/`
- `.gitignore`
- `.env.example`
- `README.md`
- `CHANGELOG.md`
- `CONTRIBUTING.md`
- `package.json`
- `package-lock.json`
- `vite.config.ts`
- `wrangler.toml`
- `tsconfig.json`
- `tsconfig.node.json`
- `tsconfig.cloudflare.json`
- `index.html`
- `src/`
- `public/`
- `functions/`
- `scripts/`
- `docs/`

## Do not upload these

- `node_modules/`
- `dist/`
- `.git/`
- `.wrangler/`
- `.DS_Store`
- `.env`

## Local test

```bash
npm install
npm run build
npm run dev
```

## Cloudflare Pages settings

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Production branch: `main`

## Phase 4 note

Cloudflare KV persistence will not work until you create KV namespaces and replace the placeholder namespace IDs in `wrangler.toml`.
