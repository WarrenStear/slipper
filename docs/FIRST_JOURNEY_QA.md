# First Journey Recipient QA

This is the manual recipient-level review for the canonical journey. Test once
with a fresh profile, once from an incomplete save, once with reduced motion,
and once on a narrow touch viewport. Canonical prose must always be sourced
from `slipperArchiveSource`; private redactions may only be replaced through
the validated, ignored `private-content/slipperGiftOverrides.json` overlay.

The checks below are review prompts, not passed results. The raw WhatsApp writing and supplied photographs outrank their cinematic interpretation. Use `EMOTIONAL_CINEMATOGRAPHY_BIBLE.md` for all 32 scene source anchors and `EMOTIONAL_ARC_QA.md` to record actual desktop/mobile/accessible/recovery evidence.

## Global threshold and return

- Fresh: black, `SLIPPER IN THE WOODS`, `A journey to you.`, and one `Begin` action.
- Incomplete: the same threshold with one `Continue the Journey` action; resume at the last safe authored scene.
- Completed: one `Return to the Woods` action. Archive, Constellation, bookmarks, revisiting, and free exploration belong only to Free Woods.
- Settings remain discreetly reachable in every state. No account prompt, counts, map, archive, or navigation tutorial competes with the invitation.
